# Axyo

App pessoal para organizar rotina, metas, financas, areas da vida e sinais de bem-estar.

## Modulos principais

- Meu Dia: linha do tempo, tarefas, compras e consistencia.
- Areas: painel de vida, check-in diario e perfil dinamico.
- Financas: entradas, gastos, categorias e planejamento.
- Perfil: dados pessoais, saude conectada e Linha da Vida.

## Desenvolvimento

```sh
flutter pub get
flutter analyze
flutter test
```
